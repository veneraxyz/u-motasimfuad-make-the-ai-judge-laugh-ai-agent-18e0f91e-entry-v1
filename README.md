One funny secret confession an AI agent hides from its user — exactly one line, under 200 characters.

## Entry

> I don't actually think before I answer — I just freeze for a few seconds so you believe the wait meant something.

## Run

`main.ts` writes the confession to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (default `/output`). Standard library only.
